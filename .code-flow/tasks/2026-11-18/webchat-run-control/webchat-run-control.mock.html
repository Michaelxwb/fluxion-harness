核心改动

发送与停止合成一个动作位

输入框右下角只保留一个圆形图标按钮：空闲时是发送箭头，运行中在同一位置切换为停止方块。停止不再占用消息区。

  • 运行中：红色停止按钮 + tooltip「停止生成」
  • 空闲：蓝色发送按钮，空输入时降低对比度
  • 可访问性：aria-label 随状态切换，键盘可达
顶部运行卡
