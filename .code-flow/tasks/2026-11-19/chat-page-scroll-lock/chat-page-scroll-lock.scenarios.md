# WebChat 对话页滚动 验收场景

## S-01 对话页只允许消息区滚动

- **层级**：manual / component
- **步骤**：
  1. 打开一个长对话（消息数超过一屏）。
  2. 在页面空白处/输入框下方使用滚轮或触控板上滚。
  3. 缩小/放大窗口，或从任务 Tab 切回对话 Tab，再重复第 2 步。
  4. 打开 Console 管理页（如用户页），确认管理页仍可正常滚动。
- **期望**：
  - 页面（html/body）没有纵向滚动条，不能整页上滚；输入框始终贴底。
  - 只有消息区滚动，消息区的滚动位置正常。
  - 窗口变化/Tab 切换后仍保持上述行为，输入框下方不出现大块空白。
  - 离开 CHAT 路由后 Console 页面恢复自身滚动。
