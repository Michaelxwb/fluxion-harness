# 任务详情细化 验收场景

## S-01 最近运行每页 10 条

- **层级**：manual / component
- **步骤**：打开一个有 20 次运行的定时任务详情。
- **期望**：列表 10 行；提示「按时间倒序 · 每页 10 条」；分页显示 `1 / 2`；翻到第 2 页显示 `11-20 / 20`。

## S-02 结果只展示一次并支持复制

- **层级**：manual / component
- **步骤**：打开定时任务详情，查看右侧运行结果；点击「复制结果」。
- **期望**：右侧只有一个「运行结果」卡片；首屏没有第二个「执行结果」文本块；复制后按钮显示「已复制」，剪贴板为完整结果正文。

## S-03 原始结果收进技术信息

- **层级**：manual / component
- **步骤**：点击任务名旁的 `i`，展开内容。
- **期望**：技术信息弹层内提供「查看原始结果 JSON」，默认不展开；首屏运行详情不出现原始 JSON 折叠块。

## S-04 后台任务默认：左子任务 / 右父任务文件

- **层级**：manual / component
- **步骤**：打开一个有 5 个子任务、8 个结果文件的后台任务。
- **期望**：左侧子任务列表（标签/状态/错误摘要/产物数/结束时间）；右侧展示父任务文件；右侧宽度明显窄于左侧；左右两栏等高。

## S-05 点击子任务内联查看结果

- **层级**：manual / component
- **步骤**：点击左侧某个子任务行。
- **期望**：URL 不变；右侧切换为该子任务的结果与文件；行有选中态；点击「父任务文件」恢复父任务文件；不进入子任务详情页。

## S-06 子任务加载失败可重试

- **层级**：component / manual
- **步骤**：选中子任务时让其执行详情接口失败。
- **期望**：右侧显示错误与重试；左侧列表保持；重试成功后显示该子任务结果。

## E-07 无子任务/无产物不回归

- **层级**：component / manual
- **步骤**：分别打开无子任务有文件、无子任务且无文件的后台任务。
- **期望**：无子任务时文件占满整行；无文件且无子任务时不渲染文件卡、不显示 0 项计数。

## S-07 运行结果扩大并滚动，文件/发送区精简

- **层级**：manual / component
- **步骤**：打开一个有长结果的定时任务运行详情，滚动结果区；再观察生成的文件与发送结果。
- **期望**：结果完整正文可见，超出高度时在卡片内上下滚动；复制仍复制全文；文件区行距更紧凑；发送结果横向排列；结果区不会把文件/发送区完全挤出。

## S-08 定时详情一屏展示

- **层级**：manual
- **步骤**：在 1440×900 打开有 10 条运行、长结果的定时任务详情。
- **期望**：页面无纵向滚动；10 条运行、分页、运行结果、文件、发送结果同屏可见；运行结果区无滚动条，长内容底部渐隐，复制仍复制全文。
