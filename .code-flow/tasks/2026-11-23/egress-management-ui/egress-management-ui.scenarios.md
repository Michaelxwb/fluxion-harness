# 出站管理人工验收

使用当前本机 Docker 的真实构建产物。涉及规则保存和回滚的场景请使用独立测试租户及测试账号。执行后记录结果与相关设置版本。

## S-01 查找监控和已有数据

- **目标**：统一入口可达，监控显示同一租户的已有结果。
- **负责**：功能验收人。
- **前置**：测试租户已有出站记录，准备普通查看账号。
- **步骤**
  1. 从左侧「出站管理」打开监控，选择一个有数据的时间范围。
  2. 通过「概览」的快捷入口和原监控书签分别进入。
  3. 查看相同时间范围内的统计和排行。
- **期望**：三个入口打开同一个出站监控页，选取同一时间范围时统计一致。
- **实际结果**：待执行。

## S-02 编辑和保存出站规则

- **目标**：规则页可独立保存，其他设置保持原值。
- **负责**：功能验收人。
- **前置**：管理员账号，已记录一个与出站无关的系统设置。
- **步骤**
  1. 在「出站规则」编辑测试规则，切到监控，再返回规则页。
  2. 确认草稿后保存并刷新。
  3. 查看前置步骤记录的系统设置。
- **期望**：跨页签草稿可继续编辑，保存后的规则可见，其他设置保持原值。规则页提供保存和重置草稿。
- **实际结果**：待执行。

## E-01 并发修改保护

- **目标**：版本已变化时，旧草稿保留并提示冲突。
- **负责**：功能验收人。
- **前置**：用两个管理员会话打开同一测试租户。
- **步骤**
  1. 在第一个会话编辑规则，暂不保存。
  2. 用第二个会话保存另一项设置。
  3. 回到第一个会话保存规则。
- **期望**：第一个会话看到版本冲突和重新加载入口，草稿仍可查看，第二个会话保存的设置仍然生效。
- **实际结果**：待执行。

## B-01 非管理员直达规则页签

- **目标**：保持现有监控与编辑权限。
- **负责**：功能验收人。
- **前置**：普通查看账号与管理员账号各一个。
- **步骤**
  1. 用普通查看账号从左侧进入出站管理，尝试打开管理员复制的规则页签链接。
  2. 改用管理员打开同一链接。
- **期望**：两者可看监控。普通查看账号访问规则地址受到权限限制，管理员可编辑。
- **实际结果**：待执行。

## B-02 回滚到旧版本时保留出站配置

- **目标**：系统设置的回滚只恢复其他设置。
- **负责**：功能验收人。
- **前置**：独立测试租户中，准备旧版本与当前版本各一份，且出站开关、规则和至少一项非出站设置的值不同。
- **步骤**
  1. 打开「出站规则」，记下当前开关和规则。
  2. 到「系统设置」的版本历史选择旧版本，阅读确认说明后执行回滚。
  3. 刷新系统设置及出站规则，检查新版本与历史列表。
- **期望**：非出站设置恢复到目标版本，出站开关和规则仍等于步骤 1 的值，历史记录仍可查阅。回滚记录为一个新版本。
- **实际结果**：待执行。
