# 出站管理前端设计

> v0.1 · 2026-11-23 · 待评审 · FEAT-01 至 FEAT-04

## 入口与页面

左侧在「项目平台」和「运行审计」所在导航区新增「出站管理」。页面采用 Console 现有页头和线形页签。使用 `/egress` 和 URL 页签状态，默认打开「出站监控」，管理员可直达 `/egress?tab=rules`。保持旧监控地址可达，通过路由转到新监控入口，概览保留一个指向监控的链接。页签切换支持浏览器前进、后退和直接打开地址。

- **出站监控**复用现有时间范围、刷新、请求统计和接口排行，保留加载、错误及空态。继续按已有权限访问。
- **出站规则**复用出站开关、规则编辑器、字段校验、重置草稿及生效说明。规则页签只对管理员展示，直接访问也须经过角色检查。监控页没有保存按钮。
- **系统设置**移除出站规则导航分组。设置表单的序列化仍保留完整基准文档和原版本校验。全局版本历史仍位于此处。更新回滚确认文案，明确本次操作保留当前出站规则。

## 保存与草稿

规则页通过现有设置状态管理和整份设置 API 读写。渲染及编辑权限仅作用于 `egress` 分组，提交时以加载所得完整文档和版本为基准，只修改出站字段。系统设置使用同样的基准版本机制携带当前出站配置，避免分组从界面移除后在整份提交中被默认值覆盖。

出站草稿在已登录控制台会话中保留在内存，切换页签、访问其他页面或浏览器后退时可返回继续编辑。规则页首次打开才加载管理数据。无需把配置写入浏览器持久存储。仍有未保存改动时启用浏览器离页提示。保存冲突和字段错误沿用现有反馈，显式重新加载前保留草稿并提示放弃改动。

## 验收与部署

人工场景见 S-01、S-02、E-01、B-01 和 B-02。计划使用 Console 前端的 TypeScript 检查和生产构建，配合仓内 `tests/frontend/test_console_shell_contract.py`、`tests/frontend/test_overview_services_contract.py`，为新入口、权限、规则保存和回滚告知补充定向回归。真实浏览器验证键盘页签、直达链接、跳转、草稿和保存结果。

发布时将构建产物装入 Console 镜像。发布前后从 Web 入口检查 SPA 和静态资源，确认 Runtime 容器继续使用已部署镜像。
