## WebChat

MessageThread 继续从同一条助手消息读取正文及 technical_details。正文由服务端按冻结的 Run locale 生成；前端不解析错误码、不推断修复人，也不生成第二份摘要。默认收起原有技术详情，使用现有原生展开控件和键盘操作。没有详情时省略控件。刷新、流式结束和重新打开会话均读取同一份已交付消息，避免追加第二份失败说明。技术字段按纯文本输出。

当本次草稿在写入前失败，正文说明本次创建结果；先前已有任务状态只有在有证据时出现。由用户补充业务值的情况直接在会话中回答。管理员修复的情况说明修复后何时可以再试，不增加转交、自动重试或切换执行方式的按钮。

## Console 运行详情与导出

沿用 run-observability 的时间线与 RunEventDetails。扩展服务层的显式字段集合及类型；调用身份、业务错误码、field/reason/repair、重试许可/处置、Agent 处置及消息来源作为该次调用的诊断展示。根因与保护关联只使用后端确认的来源 ID；Run 头部显示实际终止原因。可空布尔按允许、禁止、未知显示。缺少诊断的历史行继续显示已有时间线字段。折叠管控只影响显示，数据访问由服务端校验租户及权限。

继续从已加载的事件数据渲染，展开、切换语言和显示新字段均不发起额外请求。只在展开项中格式化结构化值。中英文标签使用现有 locale 文件；枚举值和调用标识保留为可复制文本。Console 导出使用相同安全字段及来源标记；无授权用户不能凭 Run ID 读取记录。
