# 总体设计图目录

正文使用中文描述性图名；文件与图名一致，不使用难以对应的纯编号。正文直接引用 SVG；如需 PNG，可由浏览器或转换工具导出。

| 图名 | 所在章节 | 生成函数 | 读图重点 |
| ---- | -------- | -------- | -------- |
| 系统组成与边界 | 5.1 | `system_boundary` | 使用方、平台组件、外部模型网关、外部服务与共享数据 |
| 逻辑分层 | 5.2.1 | `logical_layers` | 用户入口、接入、执行、能力、数据与管理面 |
| 模块依赖关系 | 5.2.2 | `module_dependency` | 逻辑模块、共享能力与依赖方向，不画工程目录 |
| 部署拓扑 | 5.5.1 | `deployment` | 工作负载、Nginx 入口、数据服务与文件存储 |
| 网络拓扑与容量规划 | 5.5.2 | `network_capacity` | 浏览器入口、企业微信直连、外部依赖 |
| 开通与绑定 | 5.3.1 | `flow_binding` | 绑定码、身份映射与回复 |
| 对话请求生命周期 | 5.3.2 | `flow_conversation` | 纯模型对话、入口差异、断线重连 |
| 同步 Skill 执行 | 5.3.3 | `flow_sync_skill` | 模型网关、平台接入、沙箱执行与回填 |
| 异步任务与结果回流 | 5.3.4 | `flow_async_task` | JOIN、DETACH、平台接入/模型网关、结果回流 |
| 定时与批量任务 | 5.3.5 | `flow_schedule_batch` | 计划触发、平台接入/模型网关、结果投递 |
| 取消当前请求与恢复 | 5.3.6 | `flow_cancel_resume` | Run 级取消、等待恢复与快照沿用 |
| Skill 导入与自建 | 5.3.7 | `flow_skill_import` | 自建提交、管理员审批、管理员直接导入 |

每张图同时输出：

- `图名.svg`：正文直接引用的矢量图；
- `图名.mmd`：便于对照的 Mermaid 结构；
- `tools/布局数据/图名.json`：节点、分组、连线与消息数据，便于调整。

修改图时只改 `tools/生成配图.py` 中对应函数，然后运行 `生成配图.sh`；正文引用与图题由 `校验配图.py` 检查。
