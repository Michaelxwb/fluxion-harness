# 数据库公共字段与表清单 V1.9.1

> **⚠️ 历史快照声明**：本文档为 V1.9.1 历史快照，已被《08-数据库表所有权与字段索引》与各模块 design-full（V1.11+）取代。表结构、字段、唯一约束一律以后者为准，本文档仅作历史演进参考。其中"公共字段规范"一节仍有效（以《04-数据库设计基线》为准）。

> 本文给出逻辑 Schema 基线。字段名可在编码前通过 SQLAlchemy/Alembic 细化，但对象关系、唯一约束、敏感边界和生命周期不得自行改变。

## 1. 控制面定义表

### 1.1 `model_config`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | UUID/TEXT | PK | |
| name | varchar | not null | 中文展示名 |
| key | varchar | unique(active) | 稳定标识 |
| protocol | varchar | `OPENAI_COMPATIBLE` | V1 固定协议 |
| base_url | varchar | not null | endpoint |
| model_name | varchar | not null | provider model id |
| api_key_secret_ref | varchar | nullable | SecretProvider ref |
| default_parameters | jsonb | schema 校验 | temperature 等 |
| enabled | bool | not null | |
| revision | int | not null | 保存即 +1 |
| is_deleted/create_time/update_time | | | 公共字段 |

编辑后对新请求直接生效，不做发布版本。

### 1.2 `agent_definition`

| 字段 | 约束/说明 |
|---|---|
| id | PK |
| name | not null |
| key | active unique，创建后不可改 |
| description | |
| instructions | system prompt/instructions |
| model_config_id | FK，V1 单模型 |
| memory_policy | enum/typed config |
| enabled | |
| revision | direct-effect revision |
| 公共字段 | 必须 |

### 1.3 `agent_capability_binding`

只表示 **Agent 直接暴露的 Capability**，不包含 Skill 内 manifest 依赖。

```text
agent_id FK
capability_id FK
enabled
UNIQUE(agent_id, capability_id) WHERE is_deleted=false
```

### 1.4 `agent_skill_binding`

```text
agent_id
skill_id
enabled
UNIQUE(agent_id, skill_id)
```

### 1.5 `agent_service_binding`

表示 Agent 可以调用的子 Service：

```text
agent_id
service_id
enabled
UNIQUE(agent_id, service_id)
```

与 `service_definition.primary_agent_id` 含义不同。

## 4. Skill

### 4.1 `skill_definition`

稳定产品身份：

| 字段 | 说明 |
|---|---|
| name/key | 从首次 manifest 建立 |
| description | 当前 artifact manifest 投影/缓存 |
| platform_label | 文本标签，无 FK |
| current_artifact_id | FK |
| enabled | Skill 是否可绑定/运行 |
| revision | 当前指针变化 |
| 公共字段 | |

一般不提供 Console 手工编辑业务字段；更新来自导入新 artifact。

### 4.2 `skill_artifact`

不可变：

| 字段 | 说明 |
|---|---|
| skill_id | FK |
| artifact_ref | ObjectStore |
| checksum | SHA-256 等 |
| manifest | 导入时冻结原始/规范化 manifest |
| sdk_version | |
| entrypoint | |
| validation_status | |
| validation_report | 可 JSONB，非运行 SoT |
| create_time | 导入时间 |

禁止 UPDATE artifact bytes/manifest/checksum。

### 4.3 `skill_artifact_capability`

**派生只读索引**，来源是 artifact manifest，便于反向查询和导入校验：

```text
artifact_id
capability_id
capability_key_snapshot
UNIQUE(artifact_id, capability_id)
```

Console 不直接写这张表。

## 6. 用户、授权、Channel

### 6.1 `platform_user`

```text
id
name
key/account
description
enabled
公共字段
```

无“来源”字段。

### 6.2 `agent_access_grant`

```text
user_id
agent_id
granted_by
granted_at
status/enabled
UNIQUE(user_id, agent_id)
```

它是使用授权，不是 Channel 路由。

### 6.3 `channel_account`

具体 Bot/接入账号：

| 字段 | 说明 |
|---|---|
| channel_type | WECOM |
| account_key/bot_id | V1 bot_id |
| secret_ref | Bot secret |
| agent_id | V1 **单值** |
| enabled | |
| connection_metadata | 非敏感连接信息 |
| last_connected_at | 可选 |

`UNIQUE(channel_type, bot_id)`。

产品 UI 位于 Agent → IM 接入，不设 Channel 一级菜单。

### 6.4 `channel_identity`

| 字段 | 说明 |
|---|---|
| channel_type | WECOM |
| tenant_key/corp_key | 如果报文可获得，用于稳定身份域 |
| external_user_id | 如 `wotvU***i4GA` |
| platform_user_id | FK |
| status | BOUND/REVOKED |
| bound_at | |

优先唯一键：

```text
(channel_type, tenant_key, external_user_id)
```

是否需要加入 channel_account_id 取决于多 Bot 身份稳定性实测，默认不要把 Bot 绑定语义写进身份。

### 6.5 `bind_code`

| 字段 | 说明 |
|---|---|
| platform_user_id | 目标用户 |
| channel_type | WECOM 等 |
| code_hash | 不存长期明文 |
| status | PENDING/USED/EXPIRED/REVOKED |
| expires_at | |
| used_at | |
| created_by | Admin |

**禁止** `agent_id`、`bot_id` 字段。

## 7. Conversation 与 Execution

### 7.1 `conversation`

```text
id
user_id
agent_id
channel_account_id nullable
status
last_message_at
公共字段
```

`/new` 创建新 conversation，身份/路由/授权不变。

### 7.2 `message`

```text
conversation_id
role
content / content_ref
message_type
trace_id
create_time
```

敏感/大附件优先 ref，不全量塞 JSON。

### 7.3 `execution`

| 字段 | 说明 |
|---|---|
| service_id/release_id | Service Execution 时 |
| user_id/agent_id | actor/context |
| conversation_id | 可选 |
| status | PENDING/RUNNING/WAITING/CANCELLING/SUCCESS/FAILED/CANCELLED |
| execution_mode | SYNC/ASYNC/混合可按实现 |
| input_snapshot | |
| context_snapshot | 非安全动态状态 |
| result_summary/result_ref | |
| error_code/error_message | 安全信息 |
| started_at/finished_at | |

### 7.4 `execution_step`

```text
execution_id
sequence
step_type
target_ref
execution_mode
status
input_snapshot
result_summary/result_ref
error_code
started_at/finished_at
```

### 7.5 `async_task_run`

一个 Execution 可有 0..N：

```text
execution_step_id
provider/type
external_task_id
status
submitted_at
last_polled_at
completed_at
result_ref
error
cancel_supported
```

### 7.6 `delivery`

保存对外投递状态，与 Execution 状态分离：

```text
execution_id
channel/account/recipient
status
attempt
last_error
delivered_at
```

## 8. Audit

`audit_log` 至少记录：

- actor；
- action；
- entity_type/entity_id；
- before/after 摘要（敏感脱敏）；
- revision/release/checksum；
- request_id/trace_id；
- create_time。

正式发布、Agent grant、Credential 更新、BindCode/解绑、Bot 配置、Skill 导入必须审计。

---

## 9. 不建表项

V1 明确不建：

- `project_integration` 业务 CRUD 表（代码部署注册）；
- `knowledge_*` 生产模型（规划）；
- `async_task` 一级产品资源表（仅 execution step 明细）；
- `user_agent_binding` 路由万能表（使用 AgentAccessGrant）；
- `skill_capability_binding` 人工维护表（用 artifact manifest 派生索引）；
- `system_setting` 用于 PG/Redis 状态；
- Channel 与 Agent 多对多路由表（V1 bot 1:1 agent）。
