# 数据库表所有权与字段索引（V1.11 模块分档拆分版）

> 本文由各模块 `design-full` 的 §3.3 汇总。字段完整定义、索引和约束以对应模块文档为准。
> Knowledge 当前规划中，不建立生产表。

## 1. 公共规则

- PostgreSQL 是 Framework 业务 SoT；Redis 不是 SoT。
- Framework 自建可变表：`id UUID` + `is_deleted` + `create_time` + `update_time`；不可变表无业务 UPDATE。
- 所有表 tenant scoped；Secret 明文不入表。
- 一个领域事实只允许一个 owner 表；禁止为了页面/Runtime 创建 shadow table。

## 2. 表所有权

| 表 | Owner 模块 | 业务字段（不含公共字段） | 关键约束摘要 |
|---|---|---|---|
| agent_definition | Agent Core 与 Agent Executor | tenant_id, name, key, description, instructions, model_config_id, memory_policy, enabled, revision | UNIQUE (tenant_id,key) WHERE is_deleted=false; model_config_id 必须属于同一 tenant 且 enabled |
| agent_capability_binding | Agent Core 与 Agent Executor | tenant_id, agent_definition_id, capability_id, enabled | UNIQUE (tenant_id,agent_definition_id,capability_id) WHERE is_deleted=false |
| agent_skill_binding | Agent Core 与 Agent Executor | tenant_id, agent_definition_id, skill_id, enabled | UNIQUE (tenant_id,agent_definition_id,skill_id) WHERE is_deleted=false |
| agent_service_binding | Agent Core 与 Agent Executor | tenant_id, agent_definition_id, service_definition_id, enabled | UNIQUE (tenant_id,agent_definition_id,service_definition_id) WHERE is_deleted=false |
| service_definition | Service 与 Execution | tenant_id, name, key, description, primary_agent_id, execution_type, draft_payload, draft_revision, current_release_id, enabled | UNIQUE (tenant_id,key) WHERE is_deleted=false; primary_agent_id NOT NULL |
| service_release | Service 与 Execution | tenant_id, service_id, release_no, content_hash, published_payload, published_by, published_at | UNIQUE (tenant_id,service_id,release_no); UNIQUE (tenant_id,content_hash) |
| execution_snapshot | Service 与 Execution | tenant_id, service_release_id, content_hash, snapshot_json, snapshot_ref | 禁止包含明文 Secret/Credential; UNIQUE (tenant_id,content_hash) |
| service_execution | Service 与 Execution | tenant_id, service_id, service_release_id, actor_user_id, primary_agent_id, conversation_id, delivery_route_id, snapshot_id, workspace_id, resource_scope_json, input_json, execution_mode, status, current_step, next_run_at, lease_owner, lease_expires_at, attempt, max_attempts, idempotency_key, trace_id, cancel_requested_at, result_ref, error_code, error_message, started_at, finished_at | UNIQUE (tenant_id,idempotency_key); 终态不可回到非终态 |
| execution_step | Service 与 Execution | tenant_id, execution_id, step_key, sequence_no, step_type, execution_mode, status, attempt, idempotency_key, input_json, output_json, result_ref, wait_until, error_code, error_detail_ref, started_at, finished_at | UNIQUE (tenant_id,execution_id,step_key); 有副作用步骤必须使用稳定 idempotency_key |
| async_task_run | Service 与 Execution | tenant_id, execution_step_id, provider_type, external_task_id, status, next_poll_at, poll_attempts, cancel_supported, result_ref, error_code, submitted_at, completed_at | UNIQUE (tenant_id,execution_step_id); 外部 task ID 不由 LLM 直接提供；必须来自 Provider 返回 |
| execution_command | Service 与 Execution | tenant_id, execution_id, actor_user_id, command_type, payload_json, status, idempotency_key, applied_at | UNIQUE (tenant_id,idempotency_key) |
| task_progress_event | Service 与 Execution | tenant_id, execution_id, event_type, stage, progress, message, visibility, occurred_at | 见模块文档 |
| artifact | Service 与 Execution | tenant_id, execution_id, execution_step_id, artifact_type, name, object_ref, checksum, content_type, size_bytes, created_by | 见模块文档 |
| capability_definition | Capability Runtime | tenant_id, name, key, description, input_schema, output_schema, risk_level, side_effect, idempotency_semantics, enabled, revision | UNIQUE (tenant_id,key) WHERE is_deleted=false; input_schema/output_schema 必须合法 |
| capability_implementation | Capability Runtime | tenant_id, capability_id, implementation_type, project_platform_id, auth_mode, config, shared_secret_ref, execution_policy, data_retrieval_policy, enabled, revision | CHECK: implementation_type=PLATFORM_SERVICE <=> project_platform_id IS NOT NULL; PLATFORM_SERVICE 必须 auth_mode=USER_PLATFORM 或明确的项目 Provider 策略 |
| skill_definition | Skill Runtime | tenant_id, name, key, description, platform_label, current_artifact_id, enabled, revision | UNIQUE (tenant_id,key) WHERE is_deleted=false; platform_label 纯文本分类，不参与认证/路由 |
| skill_artifact | Skill Runtime | tenant_id, skill_id, artifact_ref, checksum, manifest_json, sdk_version, entrypoint, validation_status, validation_report, created_by | UNIQUE (tenant_id,checksum); 禁止 UPDATE artifact 内容；validation_report 若需复核可追加 validation event 或仅更新状态（实现需选择并保持审计） |
| skill_artifact_capability | Skill Runtime | tenant_id, artifact_id, capability_id, capability_key_snapshot | UNIQUE (tenant_id,artifact_id,capability_id); 仅导入器写入，不暴露 CRUD |
| project_platform | Auth 与项目平台 | tenant_id, name, key, description, auth_type, auth_schema, enabled, revision | UNIQUE (tenant_id,key) WHERE is_deleted=false; auth_schema 必须通过 JSON Schema/Pydantic 校验 |
| user_project_credential | Auth 与项目平台 | tenant_id, platform_user_id, project_platform_id, credential_ref, external_session_ref, expires_at, status, verified_at, metadata, revision | UNIQUE (tenant_id,platform_user_id,project_platform_id) WHERE is_deleted=false; 明文用户名/密码/token 不得进入 metadata/log |
| channel_account | Channel Gateway | tenant_id, channel_type, account_key, secret_ref, agent_id, enabled, connection_metadata, last_connected_at, revision | UNIQUE (tenant_id,channel_type,account_key) WHERE is_deleted=false; WECOM: UNIQUE (tenant_id,agent_id,channel_type) WHERE enabled=true AND is_deleted=false |
| channel_identity | Channel Gateway | tenant_id, channel_type, identity_scope_key, external_user_id, raw_identity_json, first_seen_at | UNIQUE (tenant_id,channel_type,identity_scope_key,external_user_id) WHERE is_deleted=false |
| channel_binding | Channel Gateway | tenant_id, platform_user_id, channel_identity_id, status, bound_at, binding_method, revoked_at | 一个 ChannelIdentity 同时最多绑定一个 PlatformUser；UNIQUE active(channel_identity_id); 同一 PlatformUser 可绑定多个外部身份 |
| bind_code | Channel Gateway | tenant_id, platform_user_id, channel_type, code_hash, status, expires_at, used_at, used_identity_id, created_by | 同一 user+channel_type 同时最多一个 PENDING 有效码；新建码使旧码 REVOKED; code_hash 不可逆 |
| channel_delivery_route | Channel Gateway | tenant_id, platform_user_id, conversation_id, channel_type, channel_account_id, peer_type, peer_id, status, last_active_at | 不得把本表作为授权事实；投递前可检查 Channel Account enabled |
| conversation | Conversation 与 User Memory | tenant_id, platform_user_id, agent_id, status, channel_type, title, last_message_at | 见模块文档 |
| message | Conversation 与 User Memory | tenant_id, conversation_id, role, content, content_ref, message_type, external_message_id, trace_id | content/content_ref 至少一个有效; 渠道 external_message_id 可按 adapter scope 唯一 |
| user_memory | Conversation 与 User Memory | tenant_id, platform_user_id, memory_key, memory_value, source_type, source_ref, status, confidence, revision | UNIQUE (tenant_id,platform_user_id,memory_key) WHERE is_deleted=false; 不得写入实时客户设备/任务状态/权限等业务权威事实 |
| workspace | Workspace 与 Sandbox | tenant_id, owner_type, owner_id, backend_type, workspace_ref, status, quota_bytes, expires_at | UNIQUE (tenant_id,owner_type,owner_id) WHERE is_deleted=false; Runtime 不直接拼 host path |
| audit_log | 可观测性与 Web 公共基础 | tenant_id, actor_user_id, action, resource_type, resource_id, request_id, trace_id, before_digest, after_digest, result, occurred_at | 禁止记录明文 Secret/password/token; append-only |
| platform_user | 用户与 Agent 授权 | tenant_id, user_key, display_name, role, status, description | UNIQUE (tenant_id, user_key) WHERE is_deleted=false; role/status 使用受控枚举或 CHECK |
| agent_access_grant | 用户与 Agent 授权 | tenant_id, platform_user_id, agent_definition_id, enabled, granted_by, granted_at, revoked_at | 同一 tenant + user + agent 只允许一条未删除记录；重复授权更新 enabled/revision 或幂等返回; 授权校验发生在身份解析之后、Runtime 执行之前 |
| model_config | 模型配置与调用 | tenant_id, name, key, protocol, base_url, model_name, api_key_secret_ref, default_parameters, extra_headers, request_timeout_ms, enabled, revision | UNIQUE (tenant_id,key) WHERE is_deleted=false; protocol=OPENAI_COMPATIBLE |

## 3. 明确不建立的表

| 不建立 | 原因 |
|---|---|
| `user_agent_binding` | 旧命名混淆路由；V1 使用 `agent_access_grant` 表达授权 |
| `integration_registration` | ProjectIntegration 是部署 Manifest/Registry 事实，不落业务 DB |
| `async_task` 一级产品表 | 使用 `async_task_run` 作为 ExecutionStep 子状态 |
| `skill_capability_binding`（Console 可写） | Skill 依赖来自 immutable Artifact 的 `skill.yaml`，使用 `skill_artifact_capability` 快照 |
| `knowledge_*` | Knowledge 仍处于规划，未冻结模型 |
| `system_settings` 管 PG/Redis | 基础设施由外部运维，不属于 Console 配置 |
