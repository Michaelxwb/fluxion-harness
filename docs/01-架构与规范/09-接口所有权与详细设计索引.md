# 接口所有权与详细设计索引（V1.14）

> **本文件由各模块 §3.4 的接口清单机械生成**（第三轮 T-15/T-55；第六轮 P1-3 定死为唯一形态）：**不允许手工编辑条目**；每个接口的请求字段、响应字段、错误码、处理逻辑都在 Owner 模块 `§3.4` 展开，本文件只做所有权与索引。
> 与模块不一致 = 本文件需要重生成（以模块为准），**不存在"两处清单各自维护、以某处为准"的第三种状态**。
> `tests/architecture/test_design_consistency.py` 保证：本文件出现的接口 ID 必须能在模块 `§3.4` 清单里找到，模块清单里的 ID 也必须在本文出现（缺一即失败）。

## 1. 所有权原则

- `platform-api` 提供 Web 公共边界，但不复制领域业务 Service。
- HTTP Endpoint 归领域模块；Runtime/Worker/SPI 模块可只暴露 Library/Internal Contract。
- Skill Dev Gateway `/dev/v1/*` 归 Skill SDK/离线开发模块，内部调用统一 CapabilityExecutor。
- Knowledge 当前不冻结接口（ADR-022）。
- 一个 Contract 只在一个模块定义（README §3）；下表每行即该接口的唯一 Owner。
- `/internal/*` 一律使用模块 09 `AUTH-LIB-02` 签发的 JWT（audience + scope）校验；`/api/v1/*` 一律登录会话（唯一豁免 `POST /api/v1/auth/login`）。
- Console 不提供会话管理（ADR-045），因此不存在 `/api/v1/conversations*`。
