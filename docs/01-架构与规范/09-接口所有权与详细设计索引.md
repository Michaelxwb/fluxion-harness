# 接口所有权与详细设计索引（V1.11 模块分档拆分版）

> 本文汇总本轮全部 HTTP / Library / CLI Contract。**每个接口的请求字段、响应字段、错误码、处理逻辑在 Owner 模块 §3.4 展开**。

## 1. 所有权原则

- `platform-api` 提供 Web 公共边界，但不复制领域业务 Service。
- HTTP Endpoint 归领域模块；Runtime/Worker/SPI 模块可只暴露 Library/Internal Contract。
- Skill Dev Gateway `/dev/v1/*` 归 Skill SDK/离线开发模块，内部调用统一 CapabilityExecutor。
- Knowledge 当前不冻结接口。
