## 3. 冻结说明

原「§3 跨模块通用码与内联码（需在各模块错误表中补登记）」已**全部并入 §2 主表**（含 Owner 与 HTTP），本节不再维护第二份清单——"先使用后补录"会让注册表永远不完整，也给了实现者两处查询来源。

规则：

- **新增错误码必须先登记 §2**（Owner 模块 + HTTP + 含义），代码里出现未登记的错误码视为契约违约；
- 跨模块通用码在 §2 中标注多个 Owner（如 `01 / 04 / 05`），模块错误表可引用但不得改写含义；
- `EXECUTION_HUMAN_TIMEOUT`/`HUMAN_TIMEOUT`/`USER_INACTION` 等**终态分类值**不是接口错误码，§2 中已标注用途。
