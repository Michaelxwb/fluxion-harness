# 数据库公共字段与表清单

> **基线**：Framework v0.3.0 / 总体设计 V1.6  
> **范围**：Framework 自建数据库表

## 1. 强制公共字段

每张 Framework 自建表必须包含：

| 字段 | 类型 | 可空 | 默认值 | 说明 |
|---|---|---:|---|---|
| `is_deleted` | BOOLEAN | N | FALSE | 逻辑删除 |
| `create_time` | TIMESTAMPTZ | N | `now()` | 创建时间 |
| `update_time` | TIMESTAMPTZ | N | `now()` | 更新时间 |

Repository 普通查询默认增加：

```sql
WHERE is_deleted = false
```

删除默认：

```sql
UPDATE <table>
SET is_deleted = true,
    update_time = now()
WHERE ...
```

`is_deleted` 为低选择性字段，不要求每张表建立单列索引；需要唯一性的业务键优先使用：

```sql
CREATE UNIQUE INDEX ...
ON ...
WHERE is_deleted = false;
```

## 3. 第三方管理表

LangGraph Checkpointer 等第三方库自行创建和升级的表不属于 Framework 自建表，不强行追加字段。

理由：

```text
第三方 Schema
→ 由第三方版本管理
→ 强改列会把 Framework 与第三方内部实现绑定
```

Framework 只保证自己的业务 Execution/Conversation/Memory 等表满足本规范。
