## 模块责任清单

| 模块 | 不可缺少的输出 |
|---|---|
| 01 Core | 领域对象、关系、不变量、发布语义 |
| 02 Platform API | Console DTO/API、Secret/write 边界 |
| 03 Agent Runtime | trusted context、无状态 realtime |
| 04 Agent Core | resolver/toolset/executor 纯度 |
| 05 Service/Execution | publish、snapshot、状态机 |
| 06 Worker | claim/recovery/retry/cancel |
| 07 Capability | Provider/Auth/Paging/Result |
| 08 Skill Runtime | Artifact/Python/SDK host |
| 09 Auth/ProjectPlatform | user×platform credential |
| 10 Channel | Bot/Identity/Grant/commands |
| 11 Conversation | message/checkpoint/memory |
| 12 Integration | deploy-time SPI |
| 13 Workspace | sandbox/files |
| 14 Infra | external adapters |
| 15 Observability | trace/log/audit/web |
| 16 Knowledge | Planning gate |
| 17 Skill SDK | local dev/mock/dev gateway/CLI |
| 18 用户与Agent授权 | platform_user/agent_access_grant/用户角色 |
| 19 模型配置与调用 | model_config/Provider 调用 |

## 追溯缺口处理规则

如果编码时发现：

- 页面需要字段但模块无数据定义；
- API DTO 无 Domain 对象；
- DB 字段无法找到业务/运行用途；
- 测试无法构造真实边界；

必须先回到相应模块设计补充，不允许在代码里形成“事实后补文档”。
