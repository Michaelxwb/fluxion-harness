## 追溯缺口处理规则

如果编码时发现：

- 页面需要字段但模块无数据定义；
- API DTO 无 Domain 对象；
- DB 字段无法找到业务/运行用途；
- 测试无法构造真实边界；

必须先回到相应模块设计补充，不允许在代码里形成“事实后补文档”。
