# 详细设计模板使用说明

本轮模块详细设计严格按三份模板的职责选择文档类型，而不是把所有模块机械套成同一种格式。

## 模板映射

| 模板 | 适用模块 | 本次应用 |
|---|---|---|
| `design-full.md` | 跨系统集成、架构核心、可靠性/安全/数据/部署复杂模块 | 核心领域、Platform API、Agent Runtime、Agent Core、ExecutionService、Worker、Capability、Knowledge、Auth、Channel、Workspace、Memory、Integration |
| `design-lite.md` | 公共支撑、单一职责、复杂度较低模块 | 存储与基础设施适配、可观测性与 Web 公共基础 |
| `design-frontend.md` | React/Vue 等前端模块 | Console 前端 |

## 填写原则

- 模板中的性能/SLA/TPS 示例数字没有作为项目真实指标使用；
- 缺少实测依据的性能、容量、SLA 均写“待定”；
- 不存在 `spec-context.yml` 时不虚构 Spec Rule；
- 模块场景编号直接作为未来测试用例来源；
- 跨 API/数据库/多进程/最终 UI 的关键流程按 E2E 验证；
- Worker crash、Redis Down、Control Plane Down、Multi-Pod、Production Sandbox 等关键真实边界不得降级为纯 mock；
- Mermaid 节点带特殊字符时使用引号，避免反向箭头和紧凑式点线语法。
