# V1.7 → V1.8 交互驱动重构说明

本轮不是兼容性补丁，而是以已评审交互为产品事实重新对齐设计。

主要变化：
1. “项目集成”产品对象更名并重构为 ProjectPlatform；原 ProjectIntegration 保持部署扩展语义。
2. 新增 AgentAccessGrant。
3. Channel 关系拆成 Account/Identity/Grant；WeCom bot_id V1 1:1 Agent。
4. `/bind` 建模为一次性身份映射流程，并补 Console IM 身份/绑定码管理。
5. Skill 重构为 Definition + immutable Artifact + Capability 依赖。
6. Skill 增加非语义 `platform_label`。
7. SOP 分为 Skill 柔性 SOP 与 Service Execution 确定性 SOP。
8. Service primary Agent 强制必填。
9. Capability 增加 Data Retrieval Policy 与自动分页终止/保护策略。
10. 异步执行统一放入 Execution/Timeline。
11. Knowledge 降为规划项。
12. 前端删除 Channel/认证配置/系统设置独立菜单，统一页面布局与时间格式。
