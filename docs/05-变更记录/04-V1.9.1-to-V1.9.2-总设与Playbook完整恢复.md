# V1.9.1 → V1.9.2：总体设计与 Playbook 完整恢复

## 背景

V1.9/V1.9.1 生成过程中，总体设计与 Playbook 曾被重新摘要化，虽然最新结论被保留，但历史完整版中的设计输入、方案选型、DFX、流程、边界、Gate、风险、旅程细节大量丢失。

## 本次原则

1. 以用户提供的完整 V1.7 总设和 V5 Playbook 为母本，不再从摘要文档反向重写；
2. 原章节、论证、历史经验、DFX、Gate、风险和详细流程默认全部保留；
3. 仅对与最新已确认结论冲突的内容做原位修订；
4. 新结论以新增章节/子章节方式补齐，避免覆盖历史论证链；
5. 总设/Playbook → 交互稿 → 模块设计 → API/DB → Code 的追溯顺序保持不变。

## 关键更新

- ProjectPlatform / ProjectIntegration 拆分；
- AgentAccessGrant；
- ChannelIdentity / Bot Route / Grant 三分离；
- 一个 bot_id 一个 Agent；
- /bind + BindCode；
- Skill 离线 Python 开发 + Skill SDK + Dev Capability Gateway；
- Skill manifest 依赖只读；
- Capability 自动分页；
- Service primary_agent_id；
- Async Task 统一 Execution Timeline；
- Knowledge 进入规划；
- 最新 Console 信息架构和角色边界。
