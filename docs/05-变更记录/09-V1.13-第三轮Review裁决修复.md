## 修改清单

### 00-总体设计
- ADR 汇总升 V1.13；ADR-034/035 修订；新增 ADR-040..048。

### 01-架构与规范
- **01-架构基线**：channel-gateway 改为「V1 单副本 + 多副本前 Gate」、依赖改为「agent-runtime 内部 REST（CH-DATA-01..04/CH-INT-02）」，删除「直连 PG / 按 Bot 分片扩容」的矛盾表述。
- **04-数据库设计基线**：公共字段规则统一（所有自建表含四字段，不可变表禁业务 UPDATE）；事务边界补 8 类新事务（Skill 两阶段、提案签发/确认、TEST 快照、人工决策、重试派生、投递许可与回写、Memory 受控写入）。
- **06-接口设计基线**：Envelope 例外补 `/metrics`（Prometheus 文本）；补 Console 登录范围声明与角色映射；Capability 元数据与实现 Schema 指向 Owner；新增 `PATCH /services/{id}/enabled` 与 `EXE-API-06`；删除 Console 会话端点；IM 命令对齐九条 + `CH-INT-02` Owner；投递改为 `attempt_token` 单次发送；Dev Gateway 引用 `AUTH-LIB-03`；幂等清单补 5 类；错误码指向新注册表；模型字段单位与 Builder 只读口径。
- **08-数据库表所有权与字段索引**：**按 Owner 重生成**——补齐 4 张缺失表（`execution_proposal` / `skill_import_preview` / `conversation_run` / `channel_command_receipt`）；修正 `execution_snapshot` 唯一键为 `(tenant_id,service_id,source,content_hash)`、`async_task_run` 为 `(tenant_id,operation_id)`、`service_execution.source` → `execution_source`；`capability_definition` / `model_config` / `user_project_credential` / `conversation` / `message` / `channel_account` 字段同步；新增 §0 一致性校验纪律。
- **09-接口所有权与详细设计索引**：**按模块 §3.4.1 重生成**（补齐 19 个缺失接口，修正 2 处签名冲突，删除已删的 Console 会话端点与 `MEM-INT-01`）。
- **新增 10-错误码与错误分类基线**：7 类错误分类（可重试性唯一依据）+ 错误码注册表（从各模块错误表汇总）。
- **05-数据库公共字段与表清单**：保持历史快照声明。

- **03 Agent Runtime / 04 Agent Core**：RT-INT-01 事件枚举补 `skill`/`file`/`proposal` 与签发步骤；新增 `RT-LIB-03` Chat Run 领取/恢复；AGCORE-LIB-02 分流改由 Contract 元数据判定；新增 FEAT-RT-06、S-RT-05..08、S-AGENT-06/07；矩阵与 verifier 修正。
- **08 Skill Runtime / 17 Skill SDK**：入口契约校验（同步 `run` + `SKILL_ENTRYPOINT_INVALID`）；发布审核后置与风险接受；`call` 返回归一化数据、禁外置、禁 Async；`ArtifactId` 收敛；Dev token 引用 `AUTH-LIB-03`；新增 RULE-SDK-06、S-SDK-05/06、E-SDK-03/04。
