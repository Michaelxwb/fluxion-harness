## 保持简单的边界

- 保留现有 Python Application 与 TypeScript Gateway 部署，不新增服务、消息队列或许可表。
- 绑定只有一个写接口；测试身份只有一份共享策略；支持模式只有一个事实字段。
- 表与接口索引由模块 Owner 生成，不再重复维护字段约束摘要。生成脚本见本次任务目录 `regenerate_indexes.py`。
- 本轮交付为设计契约、模型/建库基线及自动检查；未实现全部业务 API、前端页面或外部发送运行逻辑。
