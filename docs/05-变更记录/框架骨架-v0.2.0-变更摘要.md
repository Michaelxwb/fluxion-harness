# 框架骨架 v0.2.0 变更摘要

> 本文仅记录设计与骨架基线，不代表所有模块已完成生产实现。

## 新增

- Workspace Domain / Contract / Policy
- SandboxExecutor Contract
- SandboxCapabilityProvider
- 内置 Capability：
  - `filesystem.read`
  - `filesystem.write`
  - `filesystem.edit`
  - `filesystem.glob`
  - `filesystem.grep`
  - `shell.execute`
- 开发态 LocalSandboxExecutor
- Capability Runtime 对高风险 / worker-preferred Capability 的实时调用拦截
- Worker CapabilityStepExecutor
- Workspace/Sandbox 安全测试与 Architecture Gate

## 保持不变

- 后端统一 Response
- 后端统一日志 / request_id / 异常
- Console 统一使用 Semi Design
- 列表统一 `StandardListPage`
- Production 四个运行角色：
  - `platform-api`
  - `agent-runtime`
  - `worker`
  - `channel-gateway`

## 明确没有新增

- Tool Center
- Tool Runtime
- 第五个应用服务
- 每用户 Workspace Pod
- “本地 subprocess 等于生产 Sandbox”的错误安全承诺
