Python location:
  /opt/python3.12/bin/python
  /usr/local/bin/python -> /opt/python3.12/bin/python3.12
  /usr/local/bin/node

Implication:
  - The shared base has no package manager, so bwrap cannot be installed with
    apt/apk/dnf inside this image.
  - bwrap must be built in a builder stage and copied in, together with its
    musl loader / libcap dependencies (or a fully static binary).
  - Python lives under /opt, so a bwrap sandbox must bind /opt read-only.
