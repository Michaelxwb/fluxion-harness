What this proves
----------------
  - UID 10001 can create a user namespace.
  - Mount / PID / network / IPC / UTS namespaces can be created.
  - tmpfs can be mounted inside the user namespace.
  - The new network namespace has no usable external connectivity.
  - The current intranet pod security context allows the primitives bwrap needs.

What this does NOT prove
------------------------
  - It does not execute the bwrap binary in the intranet Pod.
  - It does not execute the real session-manager CLI inside bwrap.
  - It does not test the real Skill package through bwrap.
  These are the remaining P0 items, after the shared base image is rebuilt with
  bwrap.
