Real intranet Pod kernel smoke:
  RESULT: PASS

Important distinction:
  - Docker's default seccomp profile blocks unshare in the local test environment.
  - The intranet Kubernetes/container runtime default, with no explicit
    seccompProfile, allowed unshare and mount in the real runtime/worker Pods.
  - Therefore no seccompProfile change is required on the tested intranet nodes.
  - The local Docker result must not be used to conclude that intranet Pods need
    seccompProfile: Unconfined.
