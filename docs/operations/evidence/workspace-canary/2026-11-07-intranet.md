# 内网 K8s workspace canary（2026-11-07）

真实边界：`kubectl exec` 进入内网 `muad` 命名空间现网的 1 个 Runtime、1 个 Worker Pod，
以运行用户 UID 10001 读写共享 PVC；Runtime 写标记后 Worker 跨 Pod 读到；两个 Pod 内用
真实 `bwrap 0.13.1` 把 workspace 子目录 bind 到挂载点写入文件。探针与清理走 Pod 内
`--probe-only` / `--cleanup-only`（`scripts/workspace_canary.py`），PVC/镜像/节点证据用
kubectl 采集。

## 环境

- 命名空间：`muad`（内网 K8s）
- Pod：runtime `muad-agent-runtime-fcbcd888c-5dr46`、worker `muad-agent-worker-87f47bd7-2gtgh`
- 节点：`middleware02`，内核 `4.18.0-372.19.1.30.po1.x86_64`，`PlatOS 1.3 (LTS)`，
  `containerd://1.6.20`
- PVC：`muad-workspaces-rwx`，`Bound` + `ReadWriteMany`，storageClass
  `muad-nfs-public-provisoner`
- 镜像：
  - `docker.sangfor.com/mss-release/muad-agent-runtime@sha256:03102f7935822093c1590d4a487e921429a8a9d5d9a62b7d698c54d5c57be7c7`
  - `docker.sangfor.com/mss-release/muad-agent-worker@sha256:8b7ea1ca0e7c94da9bdbf086298783381e24a93b8098a3563f54e2b057d178a1`

## 命令

```bash
NS=muad
RUN_ID=canary-$(date +%Y%m%d%H%M%S)
RUNTIME_POD=$(kubectl -n "$NS" get pod -l app=muad-agent-runtime -o jsonpath='{.items[0].metadata.name}')
WORKER_POD=$(kubectl -n "$NS" get pod -l app=muad-agent-worker -o jsonpath='{.items[0].metadata.name}')

kubectl -n "$NS" cp ./workspace_canary.py "$RUNTIME_POD":/tmp/workspace_canary.py
kubectl -n "$NS" cp ./workspace_canary.py "$WORKER_POD":/tmp/workspace_canary.py

kubectl -n "$NS" exec "$RUNTIME_POD" -- env CANARY_ROLE=runtime CANARY_RUN_ID="$RUN_ID" \
  WORKSPACE_ROOT=/mnt/muad-workspaces python /tmp/workspace_canary.py --probe-only
kubectl -n "$NS" exec "$WORKER_POD" -- env CANARY_ROLE=worker CANARY_RUN_ID="$RUN_ID" \
  WORKSPACE_ROOT=/mnt/muad-workspaces python /tmp/workspace_canary.py --probe-only

kubectl -n "$NS" get pvc muad-workspaces-rwx \
  -o jsonpath='{.status.phase}{" "}{.spec.accessModes}{" "}{.spec.storageClassName}{"\n"}'
for POD in "$RUNTIME_POD" "$WORKER_POD"; do
  kubectl -n "$NS" get pod "$POD" -o go-template='{{.metadata.name}} {{.spec.nodeName}} {{(index .status.containerStatuses 0).imageID}} {{range .spec.containers}}{{range .volumeMounts}}{{if eq .name "workspaces"}}{{.mountPath}}{{end}}{{end}}{{end}}{{"\n"}}'
done
for NODE in $(kubectl -n "$NS" get pod "$RUNTIME_POD" "$WORKER_POD" -o jsonpath='{range .items[*]}{.spec.nodeName}{"\n"}{end}' | sort -u); do
  kubectl get node "$NODE" -o jsonpath='{.metadata.name}{" "}{.status.nodeInfo.kernelVersion}{" "}{.status.nodeInfo.osImage}{" "}{.status.nodeInfo.containerRuntimeVersion}{"\n"}'
done

kubectl -n "$NS" exec "$RUNTIME_POD" -- env CANARY_RUN_ID="$RUN_ID" \
  WORKSPACE_ROOT=/mnt/muad-workspaces python /tmp/workspace_canary.py --cleanup-only
```

## 结论：PASS

| 检查项 | 结果 |
|---|---|
| `pvc_bound_rwx` | `Bound` + `ReadWriteMany`（`muad-nfs-public-provisoner`） |
| `runtime_mounts_workspace` / `worker_mounts_workspace` | 两个 Pod 均挂载 `muad-workspaces-rwx` 于 `/mnt/muad-workspaces` |
| `runtime_bwrap` / `worker_bwrap` | `bubblewrap 0.13.1`，以 UID 10001 运行 |
| `runtime_pvc_write` / `worker_pvc_write` | 两个 Pod 均在共享 PVC 写入成功 |
| `worker_cross_pod_read` | `cross_pod_ok: true`（Runtime 写、Worker 读） |
| `bwrap_write_ok` | 两个 Pod 内 bwrap bind 的 workspace 子目录写入成功 |
| `image_digest` | 两个 `imageID` 均为 `@sha256:` digest |
| `node_fingerprint` | `middleware02`：kernel / OS / containerd 已记录 |
| `workspace_cleanup` | `.canary/<run-id>` 已删除（`removed: true`） |

备注：两个 Pod 本次都调度在 `middleware02`。跨 Pod 共享已由 NFS RWX 卷上的写读验证；
若后续要额外证明跨节点，可把其中一个副本调度到另一节点再跑一次探针。
